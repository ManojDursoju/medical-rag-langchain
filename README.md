# Medical RAG LangChain

A production-style Retrieval-Augmented Generation (RAG) system that answers
brain tumor clinical questions using PubMed and WHO medical documents.

## Tech Stack

- LangChain
- LangGraph
- FAISS
- OpenAI Embeddings
- FastAPI
- Streamlit

## Project Structure

- data/ → PDFs & Vector Database
- src/ → Core RAG pipeline
- app/ → User Interface
